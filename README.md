# Manager

Content- und Growth-Manager für **dein.Finanzbruder** als Progressive Web App fürs iPad/iPhone:
Video-Pakete (Skript, Schnittliste, Caption, Cover), Zahlen & Wochenreport, Wochenplan, Ideen –
optional mit YouTube-/Instagram-Statistiken und KI.

Alle Daten liegen verschlüsselt auf dem Gerät. Dieses Repo enthält nur Code und erfundene Demo-Daten.

App: https://jannebromann30092026.github.io/Manager/

## Installieren
1. Die URL in Safari öffnen.
2. Teilen-Symbol → **Zum Home-Bildschirm**.
3. Ab dann immer über das Homescreen-Icon öffnen.
